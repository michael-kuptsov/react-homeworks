Домашние работы по React: отдельная папка для каждого задания.

## Задания

- [ДЗ №41 — список студентов](hw-41-students/ASSIGNMENT.md). Пока создан только шаблон React/Vite; решение пишется самостоятельно по шагам.

## Запуск ДЗ №41

```bash
cd hw-41-students
npm install
npm run dev
```

Зависимости node_modules не хранятся в Git. После клонирования на другом компьютере их нужно установить.

# ДЗ №41 — список студентов в состоянии React

Источник: https://github.com/ilyalipshits/courses_catalog_40/blob/l41_state/HW_41_text.md

## Основная часть

- Компонент StudentList.
- Массив студентов в useState: Anna (id 1) и David (id 2).
- Вывод через map с key по id.
- Добавление студента через setStudents с созданием нового массива, без push в массив состояния.
- Подсказка преподавателя для нового id: crypto.randomUUID().

## Дополнительная часть ADV

Удаление студента по id через filter и обновление состояния новым массивом.

## Наш порядок работы

1. Написать компонент с обычным массивом и вывести двух студентов.
2. Разобрать useState: текущее значение и функция обновления.
3. Перенести массив в состояние.
4. Добавить кнопку добавления студента без мутации массива.
5. Проверить несколько добавлений и уникальность key.
6. Разобрать и написать удаление.

Код пишет ученик. Один шаг за раз, объяснение → попытка → проверка.
